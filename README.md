# Yayang — Personal Portfolio

Creative developer portfolio for [yayangkasep.my.id](https://yayangkasep.my.id).

## Stack

- React 19 + Vite 8
- Framer Motion
- Vanilla CSS (design tokens)
- oxlint

## Scripts

```bash
npm install
npm run dev      # local dev server
npm run build    # production build
npm run preview  # preview build
npm run lint     # oxlint
```

## Content

Edit site data in `src/data/content.js` (projects, experience, social links, email).

Contact form opens the visitor's mail client via `mailto:` until a backend (Formspree, API, etc.) is connected.
